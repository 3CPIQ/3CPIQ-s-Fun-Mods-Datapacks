# Universal Storage Search

Universal Storage Search (USS) is a client-side Minecraft mod designed to make finding your stored items much easier

Instead of checking every chest manually, USS remembers the contents of storage blocks you have already opened and lets you search through them from one menu

## Features

- Search for items stored in containers you have already opened
- See exactly where an item is stored
- Supports Chests, Double Chests, Trapped Chests, Barrels, Shulker Boxes, Ender Chests, Furnaces, Blast Furnaces, Smokers, Hoppers, Droppers and Dispensers
- Rename storage containers with custom USS names
- Filter and sort stored items
- Highlight storage locations
- Create waypoints
- Teleport to storage locations when cheats/permissions allow it
- Separate storage data for each world/server
- Automatically removes remembered storage locations when the container no longer exists

> USS does not scan containers you have never opened. It only remembers storage you have personally accessed

## Controls

Press Y to open the main USS menu
